# Financial Variance Analysis Dashboard

A modern React-based dashboard for analyzing financial variances across different General Ledger (GL) accounts. This application provides detailed waterfall analysis, key metrics, and actionable recommendations for financial decision-making.

## Features

- **Comprehensive GL Analysis**: Track and analyze variances across multiple GL accounts including:
  - Cash and Cash Equivalents
  - Accounts Receivable
  - Inventory
  - Prepaid Expenses
  - Fixed Assets
  - Investments
  - Accounts Payable
  - Short-term Debt

- **Detailed Waterfall Analysis**: For each GL account:
  - Clear progression from previous to current month
  - Breakdown of contributing factors
  - Detailed component analysis
  - Impact assessment

- **Key Metrics Tracking**:
  - Account-specific KPIs
  - Trend analysis
  - Performance indicators
  - Change tracking

- **Smart Recommendations**:
  - Action items based on analysis
  - Strategic suggestions
  - Risk mitigation steps
  - Optimization opportunities

## Technology Stack

- React
- Material-UI (MUI)
- JavaScript/ES6+

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/financial-variance-analysis.git
   ```

2. Install dependencies:
   ```bash
   cd financial-variance-analysis
   npm install
   ```

3. Start the development server:
   ```bash
   npm start
   ```

4. Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

## Usage

1. View the main dashboard showing all GL accounts
2. Click on any account to see detailed analysis
3. Review the waterfall analysis showing movement from previous to current month
4. Check key metrics and recommendations
5. Use insights for financial decision-making
